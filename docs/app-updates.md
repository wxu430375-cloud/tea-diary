# 应用内更新

从 v1.3.0 开始，可以在「茶茶手账 → 检查更新」或「数据与备份 → 检查更新」查看新版说明，点击「下载更新并重启」即可更新。v1.2.0 及更早版本需要先手动安装一次 v1.3.0。

自动检查默认关闭，可在数据与备份里开启。开启后启动时每天最多检查一次；只提醒新版本，安装由用户决定。不上传手账、照片或识别文字。离线照常使用，联网失败可稍后重试。

更新包通过 HTTPS 从本项目 GitHub 仓库下载，清单使用 Ed25519 签名，客户端内置公钥。安装前检查签名、版本、目标地址、大小、SHA-256、应用标识和 macOS 代码签名完整性。代码签名仍为原有的本地签名；更新签名独立验证发布者。新版需要的 macOS 高于当前系统时只提示，不安装。

更新先在目标应用旁准备文件，确认有写入权限后才退出。助手等待旧进程结束，替换原路径，重新打开应用；替换或启动失败时尝试恢复原版本并报告错误。用户数据目录不参与替换。成功后清理临时文件，不在应用目录留下第二个 App。从安装磁盘或只读位置运行时，会提示先拖入应用程序文件夹，不申请管理员权限。

编辑中的打卡或自创饮品需要先保存或关闭。下载和准备期间可取消，退出请求会先取消当前操作。断电或强制终止助手不保证自动恢复；如遇异常，数据仍在 `~/Library/Application Support/TeaDiary/`，可手动重新安装。

## 发布新版

1. 更新 `VERSION`、界面版本及构建号，添加 `docs/releases/<版本>.txt`。
2. 运行 `bash scripts/build-mac.sh` 和 `bash scripts/package-mac.sh`。
3. 运行 `bash scripts/prepare-update.sh`，生成版本 ZIP 与签名后的 `updates/stable.json`。
4. 运行更新测试，确认实际下载与重启后，将版本 ZIP（被默认忽略，须显式添加）和清单一起发布到 main。版本包路径固定，不覆盖已发布版本包；未来发布继续沿用同一公钥。

发布私钥在本机 `.local/update-ed25519.key`，权限为仅本人可读写，已排除 Git、源码归档及安装包。维护者应另行离线备份。丢失后不能向现有安装发布可验证更新，不能直接生成新密钥替代。开源复刻项目应生成自己的密钥、修改 feed 与允许的下载仓库、独立发布，不使用本项目的更新源。

测试：`swiftc -module-cache-path build/module-cache tests/updater.swift native/UpdateCore.swift native/UpdateTrust.swift -o build/test-updater && build/test-updater`。
