茶茶手账 v1.0.0

1. 把「茶茶手账.app」拖到 Applications 文件夹。
2. 打开应用，点「记下今天这一杯」，选择清晰的杯身标签照片。
3. 核对识别出的品牌、单品、甜度、冰量，选择日期，再收藏到日历。
4. 可以从「数据与备份」打开示例手账，看满页贴纸的效果。
5. 记得定期导出包含照片的 JSON 备份。

要求：Apple Silicon Mac，macOS 13 或更新版本。
无需 Python / Node / Java / AI 密钥。
照片通过 macOS 自带 Vision 在本机识别，不会发送到云端。

此安装包是本地临时签名版本，尚未完成 Apple 开发者公证。
如果首次被系统提示未验证开发者，请使用「右键 → 打开」或系统提供的“仍要打开”。
请勿为此关闭系统安全保护。

数据目录：~/Library/Application Support/TeaDiary/
卸载应用不会删除此目录。迁移电脑前先导出备份。

资料库为可扩展的初始版本，11个品牌37款单品，并非完整实时菜单。
贴纸是食材主题的艺术创作，部分风味复用素材，其他款使用程序手绘。
未知单品可以点「自创一杯」，模糊标签可以手动修正识别文字。
